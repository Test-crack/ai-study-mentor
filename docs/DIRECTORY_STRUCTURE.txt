Key Principles
==============

1. Feature-Based Organization
   - Code organized by business domain
   - Each feature is self-contained
   - Clear boundaries between features

2. Barrel Exports
   - Each feature exports through index.ts
   - Import from feature, not internal files
   - Example: import { useAuth } from '@/features/auth'

3. Shared Code
   - Truly shared code lives in shared/
   - UI components, hooks, utilities
   - No feature-specific logic

4. Dependency Flow
   Features → Shared → External Libraries
   - Features can use shared code
   - Shared cannot depend on features
   - Features should not depend on each other

5. Scalability
   - Easy to add new features
   - Clear ownership boundaries
   - Independent development


Import Patterns
===============

✅ CORRECT:
import { useAuth, AuthPage } from '@/features/auth';
import { Button, Card } from '@/shared/components/ui';
import { useToast } from '@/shared/hooks';

❌ INCORRECT:
import { useAuth } from '@/features/auth/hooks/useAuth';
import { Button } from '@/shared/components/ui/button';
