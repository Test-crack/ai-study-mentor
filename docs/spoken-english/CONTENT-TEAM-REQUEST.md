# Content Team Request — Spoken English diagnostic assets (Phase 3)

---

**Subject: Assets needed to build the Spoken English diagnostic**

Hi team,

We're building the **Spoken English (CEFR-aligned) speaking diagnostic**. It's a **single 8-prompt spoken viva** (record-and-submit) for **general adult learners**, targeting **A1–B2**. Paul has provided the rubric and drafted the 8 prompts; we need you to produce the following so we can load them into the system.

### 1. Finalise the 8 prompt texts
The 8 prompts (below) form a **difficulty ladder** — 1–3 are answerable at A1–A2, 4–6 need B1, 7–8 need B2+. Please **review and finalise the exact wording** for clarity and neutrality. Keep the ladder and the types.

| # | Type | Prompt | Prep | Speak |
|---|---|---|---|---|
| 1 | Warm-up | Tell us about yourself — your name, where you're from, and what you do. | 0s | 45s |
| 2 | Routine | Describe a typical day for you, from morning to evening. | 10s | 60s |
| 3 | Description | Describe a place you know well — home, neighbourhood, or workplace. What's it like, and what do you like about it? | 15s | 75s |
| 4 | Narration | Tell us about a journey or a day you remember clearly. What happened, and why has it stayed with you? | 20s | 90s |
| 5 | Opinion | If you could change one thing about where you live, what would it be and why? | 20s | 90s |
| 6 | Reply task | *(student first hears a ~20s voice message — see asset #3)* Reply to your friend: give your advice and reasons. | 20s | 90s |
| 7 | Compare | Some prefer learning in a classroom, others online. Compare the two and say which suits you better. | 25s | 105s |
| 8 | Abstract | If you ran education in your state for a year, what would you change — and what would be hard about actually doing it? | 30s | 120s |

**Rules for wording:** no cultural/specialist/regional knowledge required; accessible to any adult; plain English.

### 2. Read-aloud audio for each of the 8 prompts
Each prompt is shown **as text AND read aloud** (so we don't accidentally test reading instead of speaking). For each of the 8 prompts we need a clear recording of the prompt being read:
- **Voice:** one consistent, clear, neutral-accented adult voice (a clear Indian English accent is fine).
- **Pace:** natural, unhurried.
- **Format:** MP3 or WAV, mono, ≥ 44.1kHz, clean (no background noise).
- *(If recording all 8 is a burden, tell us — we can generate natural TTS for the read-aloud instead. Your call; recorded is warmer.)*

### 3. Prompt 6 stimulus — the voice message (required, can't be skipped)
Prompt 6 is a **reply-to-a-voice-message** task — this is the only prompt that tests "Responsiveness," so it needs a real stimulus:
- **Script:** a friend leaving a ~20-second voice message asking for advice about **whether to take a new job in another city** (mention the dilemma naturally — better pay/role vs leaving family/friends). Conversational, first-person, informal.
- **Recording:** natural conversational delivery, ~20s, same format specs as above.

### 4. Alternate sets (for retake integrity) — nice-to-have, structure now
So a student who retakes doesn't get identical prompts, please also draft **2 more parallel sets of 8 prompts** following the **same ladder and types** (same difficulty progression, different topics). We'll load one set now and add these later — no rush, but drafting them now keeps them consistent.

### 5. What we do **NOT** need (please don't spend time on it)
- **No model answers / answer keys per prompt.** Scoring is done against CEFR rubric descriptors, not per-question correct answers. Sample answers are unnecessary for launch.
- No level-tagging of prompts — it's one universal set by design.

### 6. Delivery format
- The finalised prompts as a simple table/sheet (prompt #, type, text, prep secs, speak secs).
- Audio files named consistently, e.g. `se_diag_v1_p1_readaloud.mp3` … `se_diag_v1_p8_readaloud.mp3`, and `se_diag_v1_p6_stimulus.mp3`.

**Priority order:** (1) finalised prompt texts + (3) the Prompt-6 stimulus are the **critical blockers** — we can start with those. (2) read-aloud audio next. (4) alternate sets last.

Thanks!
